Optional Google Docs export

1. Enable the Google Drive and Google Docs APIs in Google Cloud. Set up the
   Google Drive OAuth2 and Google Docs OAuth2 credentials in n8n.
2. Select those credentials in the Multi-Agent UI - Google Docs API workflow.
   Replace REPLACE_WITH_GOOGLE_DRIVE_FOLDER_ID with the target folder ID.
3. Select the X-Multi-Agent-Key Header Auth credential on the webhook and
   check the folder's sharing settings. Publish the workflow.
4. With Docker, run GOOGLE_DOCS_ENABLED=true bash scripts/start.sh. For
   manual setup, set GOOGLE_DOCS_ENABLED=true in ui/.env.local and restart the UI.

The export sends the question and the short decision report to Google. The
report omits raw attachments and independent expert replies.
