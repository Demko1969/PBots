Connect to OpenAI

With Docker, create your local n8n owner account first. Return to Ortak Akıl,
open Settings, and enter your OpenAI API key. Setup saves the key in n8n's
credential store and generates a separate token for local webhook access.

For manual setup, save the OpenAI key in an n8n Header Auth credential named
Authorization. Select it on the four OpenAI request nodes in Planner, Worker
and Judge. The four UI webhooks use a separate Header Auth credential named
X-Multi-Agent-Key. Set the matching token in the UI server's private
ui/.env.local file.

Questions, CSV samples, and analysis context are shared with OpenAI. Entire
JPG, PNG, and PDF attachments are sent for analysis. Evaluations use the OpenAI
API. See deployment/README.md for the complete steps and SECURITY.md for
details on data retention.
